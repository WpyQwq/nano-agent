# Nano 智能体工作台

基于 JavaScript、Electron 与 LangChain 的 Windows 本地智能体。默认简体中文，使用中性深色界面；支持浅色、系统主题与自定义字号。

## 启动

```powershell
cd E:\Nano
npm install
npm start
```

依赖已安装时直接 `npm start`。Node.js 需满足所安装 LangChain 的运行要求，建议 Node.js 22 或更新版本。

## 模型连接

打开 **设置 → 模型连接**，选择 OpenAI 兼容或 Anthropic 兼容服务，填写模型名称、API 地址与密钥，然后测试连接并保存。地址留空使用对应服务默认地址。OpenAI 兼容地址会保留自定义路径；支持填写 `/v1` 或完整 `/chat/completions` 地址。Anthropic 地址支持根路径、`/v1` 或 `/v1/messages`。

默认是演示模式，明确告知模型未配置，不伪造任务执行结果。项目中的测试使用本地模拟模型与 HTTP 服务，不消耗模型额度。

## 功能

- 真实会话：新建、切换、搜索、重命名、置顶、归档/恢复、Markdown 导出与草稿保存。
- LangChain：`createAgent`、真实流式输出、工具执行循环、工具失败反馈、轮数限制、按运行 ID 路由事件。
- 长任务：模型可更新工作计划；支持只读规划/实际构建切换、询问用户、排队补充要求、依据未完成计划继续执行。
- 权限：按需确认、仅观察、完全访问；支持允许/拒绝后继续，支持停止模型、命令与等待审批的任务。
- 上下文：读取与搜索项目文件、文件预览、添加文件到下一轮上下文、来源与变更面板、真实增删行数及差异。
- 开发工具：PowerShell 命令、停止命令、Git 状态、暂存和未暂存差异；非 Git 项目仍可查看 Nano 的修改记录。
- 变更审阅：文件修改创建持久快照，支持逐项接受与恢复；恢复前检查文件是否已被再次修改，避免覆盖用户的新改动。
- MCP 扩展：设置中添加本地 stdio 或 Streamable HTTP 服务，明确连接后将工具注册到 LangChain；支持工具发现、断开、超时与取消。外部工具默认逐次确认，只有扩展和工具均声明只读时才能免确认。
- 历史：保存完整模型/工具消息；错误与取消不清空历史，取消的工具调用补齐中断结果；应用关闭后可以继续对话，不自动重放未完成操作。
- 上下文压缩：会话菜单中生成工作摘要，保留原始对话，并将摘要与计划带入后续模型调用。
- 个性化：主题、统一字号、系统提示词、执行轮数、快捷键。
- 高级功能：**设置 → 智能体 → 高级功能 → 电脑操控**。保留截图、窗口列表、鼠标/键盘/滚动操作；图像理解需要模型支持视觉输入。桌面自动化目前使用 Windows 原生接口，不含 UI Automation、OCR 或浏览器 DOM 控制。

文件工具限制在用户选择的项目内，并拒绝符号链接越界和 `.nano` 数据目录。删除文件使用回收站工具并始终请求确认。完全访问模式允许执行任意项目命令，不是操作系统沙箱；请根据任务选择权限模式。

## 本地数据

默认保存在项目旁的 `.nano` 目录，避免占用系统盘。API 密钥和 MCP 环境变量由 Electron `safeStorage` 使用系统机制加密，渲染页面只获取是否存在密钥。已有旧版浏览器明文配置会在成功加密保存后迁移。会话、草稿、来源和执行历史均保存在本机；历史截图不永久嵌入会话，以控制体积。可通过 `NANO_DATA_PATH` 指定独立数据目录用于开发和测试。

图标来自 Lucide，字体使用随附 Nunito Sans 拉丁字体与本机 Noto Sans SC / 微软雅黑。第三方字体许可见 `assets/fonts/OFL.txt`。

执行与交互设计参考了 [OpenCode 开源项目](https://github.com/anomalyco/opencode)，本次查阅版本为 `8aa00e805e1b17a413d10f651c7bbdac8fd754fa`：工作计划、审批状态机、逐轮差异、MCP 连接生命周期和滚动状态管理。Nano 继续使用自身 JavaScript/Electron/LangChain 实现，没有引入 OpenCode 的运行时或复制其完整应用。

## 检查

```powershell
npm run check
npm test
```

测试覆盖流式工具循环、审批与拒绝、工具异常、取消、历史连续性、系统提示词、视觉工具内容、循环上限、模型地址、路径边界、并发持久化和密钥存储。

快捷键：`Ctrl+N` 新建会话，`Ctrl+K` 搜索，`Ctrl+,` 设置，`Esc` 停止运行；`Enter` 发送，`Shift+Enter` 换行。
